# Bounded receiver-head adaptation (registered 2026-11-23 KST)

Question: does the recorded receiver-use gap persist under normal access, and can a small supervised adaptation of the actual acting receiver head improve fresh closed-loop behavior? This extends the existing broadcast diagnostic without changing historical code, checkpoints or claims.

Contract: ten existing broadcast RR checkpoints, five agents, Medium/2 ms, fixed 0.5 ms readiness, original cache/channel semantics. Compare unchanged follower head, 100 full-batch Adam updates using true current-bit labels, and the identical update budget using shuffled labels. Fit only on the first ten saved episodes of each access regime; independently evaluate all arms on twenty fresh matched reset episodes 17300000–17300019. Normal and source-aware access are separate strata, with all ten seeds equally weighted. Encoder, message, mixer and source-action head weights remain frozen. Receiver action changes may alter later recurrent inputs/messages; evaluation executes the actual resulting trajectories rather than reusing frozen features. Source-aware identity is privileged and supplied; this is not a new learned scheduler.

Strongest controls: unchanged policy, identical-budget shuffled labels, normal-access held-out probe, identical source-head behavior on identical input, frozen-parameter checks, original historical feature/policy reproduction, episode-disjoint fitting and evaluation, and paired wire/payload counts. Probe training uses the same saved fit partition and fresh unchanged-policy evaluation inputs. A probe result is not substituted for acting performance.

Competing explanations: supervised labels, source-aware distribution shift, changed action-history distribution and decoder capacity. A positive result establishes only a bounded supervised head remedy for these existing models. It does not isolate the MARL optimization cause or establish a label-free remedy. Failure remains evidence against this particular 100-update remedy; no tuning or budget extension follows.

Adoption criterion: per access regime, true-label minus original and true-label minus shuffled-label mean accuracy must have positive seed-level 95% t confidence intervals, with unchanged paired delivery counts and all correctness checks passing. The two intervals per stratum are descriptive, unadjusted; this is a diagnostic gate, not broad confirmatory inference. The original broadcast ideal-link learning gate (at least 8/10 seeds >=75% at Medium/2 ms) must pass before interpretation. Neither access stratum must succeed for the other to be reported, and all outcomes are retained.

Budget: CPU only, one torch thread, at most 600 seconds for the main run; no GPU or full MARL training. One separate seed-0 smoke (two test episodes, ten updates) precedes execution. One fixed source-aware choice uses a cloned factual harness to preserve available packet count; its extra CPU time is separately recorded and included in total diagnostic compute. Readiness remains virtual and does not turn those overheads into real deployed delivery guarantees. All arms use the same follower/source wrapper. Offline fitting time and parameter count are reported separately.

Entry: `python -m experiments.deadline_comm.receiver_adaptation.evaluate --config experiments/deadline_comm/configs/receiver_head_adaptation.yaml [--smoke]`.
Outputs: unique run directory containing registration, input hashes, per-step/per-episode logs, fitted head states, seed summaries, aggregate confidence intervals and status. New files are isolated under this component and config; no shared training pipeline is changed. Configuration must be copied to a new output path before rerunning.

Status: completed; bounded diagnostic criteria pass for both access strata. Sources: existing `tmlr_revision/robustness/aggregate_probe.py`, `selection_validation/harness.py`, and custom `reviewer_validation/hidden_source.py`; no new external reference. The original broadcast task's reward is follower accuracy per step and episodic return is its sum over 20 steps. Primary purpose is to distinguish delivered information from behavior under a limited adaptation, not claim new benchmark generality.

Implementation check: first smoke `receiver_head_adaptation_20261123_001_smoke` failed an exact source-output assertion because evaluating a sliced source batch changed floating-point arithmetic. It remains preserved. The wrapper now evaluates both source and follower heads on the original full batch and combines their outputs; this doubled head computation is charged equally to every arm. Revised `_smoke_v2` completed all six cells. Existing intervention regression suite: five tests passed. The fixed 100-update main run subsequently completed; no scientific adoption is inferred from smoke outcomes.


## Completed results and limits

Main artifacts: `../runs/receiver_head_adaptation_20261123_001/{registration.json,input_hashes.json,episodes.jsonl,summary.json,raw_audit.json,status.json}` and 40 fitted head state files. Runtime 49.92 s; fitting totals 3.06 s. All 10 seeds retained, 60 cells, 1,200 episodes, 24,000 actual environment steps. Original ideal-link learning gate passes 10/10. Source/head identity for identical inputs, frozen non-utility parameters and historical feature predictions all pass. New head/source isolation tests and existing intervention regression results are recorded below.

| Access | Unchanged actual policy | True-label adapted policy | Shuffled-label adapted policy | Aggregate probe of unchanged policy inputs |
| --- | ---: | ---: | ---: | ---: |
| Normal | 56.575% | 63.006% | 48.100% | 69.369% |
| Source-aware | 65.075% | 87.744% | 51.006% | 99.944% |

Ten-seed paired true-label minus original gains: normal +6.431 percentage points [3.322, 9.540], source-aware +22.669 [13.279, 32.058]. True-label minus shuffled-label: normal +14.906 [10.042, 19.771], source-aware +36.738 [22.346, 51.129]. Normal aggregate-probe minus unchanged policy: +12.794 [8.116, 17.471]. All intervals are descriptive, unadjusted Student-t intervals over seed means; seed values are retained. Normal adaptation is not universally positive: seed 3 falls 1.1875 points. Normal-use gap remains on the unchanged access distribution; this counters an explanation based solely on source-aware intervention shift.

Every compared step offers 96 wire bytes and delivers 64 payload bytes; paired sender IDs and timestamps agree. Source delivery is 40% normal and 100% source-aware. Adaptation changes actual actions and therefore later histories, even with encoder/message/source-head weights frozen. Source actions differ from original in 423/4,000 normal and 409/4,000 source-aware adapted steps. Thus neither received message content nor the source's behavior is held fixed; this is the closed-loop total effect of follower-head parameter adaptation. It is not a pure fixed-message decoding intervention. An initially overstrong post-run raw-audit assertion incorrectly demanded source-action identity across different input histories; that failed check is preserved as `raw_audit_attempt_001.json`. Rechecking the registered same-input/weight/count invariants and all executed rewards passed (`raw_audit.json`). No experiment output or hypothesis was overwritten.

Computation is a material negative result: mean inclusive CPU time is approximately 775.6/792.7/779.8 microseconds for normal original/adapted/shuffled, and 2179.7/2124.4/2122.7 microseconds under source-aware access. Source-aware selection diagnostics add approximately 1.27 ms per step and all source-aware steps miss the 2 ms deadline once this extra work and modeled waiting are charged. Normal miss fractions are 1.625%, 3.525%, 2.050%. These timings include the shared double-head wrapper, instrumentation and uncalibrated current-process conditions; no steady-state speed claim or timing improvement is made. Fixed readiness allows the causal delivery comparison but does not guarantee real-time feasibility; returns do not impose an additional missed-action fallback. The result supports a supervised behavioral remedy under virtual readiness, not a deployable deadline-constrained controller.

Adoption: retain as a bounded case-study result and a normal-access confirmation, conditional on supervised current-bit labels and the stated receiver architecture. No new generic MARL objective, no native VBC/TMC conclusion, and no standard-benchmark generalization. Next hypothesis is whether a label-free or reward-matched update improves receiver use without the source-aware diagnostic overhead; no further experiment is authorized or launched by this closure.
