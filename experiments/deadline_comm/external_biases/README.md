Status: completed 2026-11-23; CPU-only bounded reconstruction, not author-code reproduction. All three both-bias seeds pass the declared validation gate at the common 12,000-update checkpoint. ## Registered experiment

Entrypoint: `python -m experiments.deadline_comm.external_biases.mnist_sum_learning --config experiments/deadline_comm/configs/external_biases_mnist.yaml`. Separate config contains question, contract, falsification and adoption gates, seeds, budget and unique output. Three independent seeds, no-bias and both-bias arms, common milestones 1,500/3,000/6,000 updates/arm (advance all arms to 6,000 only if any both-bias validation gate fails at 3,000), batch 32, 1 CPU thread and 30-minute total limit. No GPU. A five-update seed-0 smoke uses a separate output suffix.

Task: two agents each observe an independent original MNIST image. Speaker sends one of 20 discrete messages; listener sees its own image and a one-hot message and chooses among 19 sums. Reward is one iff the predicted sum is correct. Joint task exploration and learning a useful discrete channel are the coordination challenge. Train images 0–49,999 train the policies; 50,000–59,999 supply disjoint validation for continuation. Test images are evaluated only at the final selected milestone and never trained on; labels enter reward and offline evaluation, never policy inputs or a supervised training loss.

Implementation follows the published MNIST architecture (conv 32/64 channels, kernel 5, stride 1, 2x2 pooling; hidden 1024; message concatenation after CNN), independent REINFORCE and Table 3 hyperparameters. Explicit reconstruction choices where unspecified: valid convolution, uniform-with-replacement image pairing, standard PyTorch initialization, no reward baseline, no gradient clipping. Positive signalling implements main-paper Eq. (3), with lambda weighting marginal entropy (the pseudocode places lambda differently). Listening implements Eq. (6)/(8) and stop-gradient directions described in prose; this is a one-step network with zero-message branch, not an additional separately trained policy. These choices prevent exact original-score reproduction claims.

Outputs: registration/provenance, loss/reward training traces, final state dictionaries, dataset hashes, sampled and exact stochastic-policy held-out accuracy, same-pair shuffled and zero-message controls, and seed-level uncertainty. Gate requires every both-bias seed to exceed 0.2 sampled accuracy and beat shuffled messages. Failure stops downstream deadline interpretation and is retained as a bounded reproduction failure, not a refutation of the published method. No new sender-selection mechanism is introduced.

Nearest tests check independent-agent gradient isolation and stopped-gradient listening losses. Shared framework files are unchanged. Paper usage: candidate external validation of the existing deadline/cache evaluation protocol; the canonical manuscript is not automatically updated by this component.

## Prospective parallel execution amendment

Before seeing the common 1,500-update results, six independent cells were scheduled to resume that complete milestone with their exact optimizer, PyTorch sampling RNG and image-pair-generator state. Entrypoint `mnist_parallel_continuation.py`, config `../configs/external_biases_mnist_parallel.yaml`, output `runs/mnist_sum_parallel_20261123_001`. Each worker uses one CPU thread; no GPUs. Original serial registration/logs/checkpoints remain intact, with terminal `handed_off` status rather than claiming serial completion. Only the explicitly verified owned serial PID is stopped after common checkpoint availability. Any later uncheckpointed serial work is discarded for all cells consistently.

All six cells advance to 3,000 and then, only on failed all-seed validation, 6,000, 12,000 and at most 24,000 updates. This is a prospective equal-budget continuation of the same method, not tuning or seed filtering. The added parallel wall cap is 1,800 seconds with up to six single-thread processes. If it expires, the last fully completed common milestone supplies the retained negative result; partially completed cells do not define the final cohort. Test data is evaluated only after validation-based stopping. Per-milestone checkpoints are preserved.

Metric contract: `original_listener_power` estimates the paper's label-assisted optimal-listener gain from the message/true-speaker-digit contingency; `original_speaker_power` compares the best label-conditioned message to a uniform message given the learned listener. Labels are offline diagnostic information only. These finite-sample oracle diagnostics can be optimistic and are not achieved rewards. `cic` is explicitly conditioned on each fixed image pair and weights message interventions by that speaker's current distribution; near-deterministic message policies can make it small despite sensitivity to alternative messages. It is not presented as an exact implementation of every Lowe/Eccles listening measure. `exact` sums all 20 message probabilities and resulting listener probabilities for the actual sum; `expected` conditions on a sampled message, and `sampled` additionally samples the listener action. The learning gate uses the declared sampled/expected quantities, not an oracle or probe.

## Executed results and decision

The 3,000-update common gate passed 0/3 both-bias seeds, 6,000 passed 1/3, and 12,000 passed 3/3. All six cells reached the same final 12,000 updates; 24,000 was not executed. Validation sampled accuracy at the selected milestone was 47.36%, 43.26%, 53.42% for seeds 0/1/2, with shuffled-input accuracies near 9–10%. No seed was discarded. The final test was then evaluated once using 2,048 unseen official-test image pairs per seed.

Final sampled-policy accuracy: both biases 49.71%, 47.51%, 53.42% (mean 50.21%, descriptive unadjusted seed-t 95% CI [42.79,57.63]); no bias 9.86%, 9.42%, 9.72% (mean 9.67%). Exact 20-message stochastic-policy expected accuracy averages 49.82% versus 9.24%; shuffled messages 9.51% and zero-message input 9.97% for the both-bias policies. The original paper's offline listener/speaker power diagnostics are positive (means 0.610 and 0.446), so this run does not show that existing information-use diagnostics miss the learned communication benefit.

Validation: three focused tests passed, five-update smoke passed, and all six model/optimizer/RNG states were tensor-identical across the common-1,500 execution handoff. Per-milestone checkpoints, training logs, failed early gates and final test records are preserved. Artifacts: `runs/mnist_sum_parallel_20261123_001/{registration.json,handoff_validation.json,validation_3000.json,validation_6000.json,validation_12000.json,summary.json,seed_summary.json,status.json}`, `seed{seed}_{arm}_{update}.pt`, and the retained serial `runs/mnist_sum_20261123_001/` with terminal handed-off status. Parallel continuation wall time was 886.7 seconds, below its 1,800-second cap, using at most six independent single-thread CPU workers. No GPU or historical training job was used.

Adoption: the checkpoints are eligible as a bounded learned reference for separately registered deadline/delivery diagnostics. This is not a reproduction of the original paper's near-perfect final scores, an author-code validation, a standard sequential-MARL benchmark result, a new learning objective or evidence that the published biases fail. MNIST-sum is a one-step two-agent task; it cannot directly test multi-sender selection or temporal cache initialization.
