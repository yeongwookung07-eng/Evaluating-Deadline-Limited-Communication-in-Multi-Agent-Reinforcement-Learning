# Frozen native SchedNet one-decision sender replay

Registered 2026-11-28 before evaluation. This study extends sender attribution to the authors' native grid Predator–Prey task. Four partially observing predators (one larger field of view) coordinate around a randomly moving prey on a 7 × 7 grid. Capture is the upstream scenario's terminal flag. Return is the undiscounted sum of the native reward vector across actions through termination or 50 steps. We keep the weak 50,000-step independently trained native weights for seeds 0–2 from the completed historical campaign. No refitting, checkpoint selection or native benchmark score reproduction. The old testing routine explores scheduling; this experiment always uses the checkpoint's greedy top-one scheduler with native stochastic actor and prey. There is one scheduled two-component learned encoding per step and schedule history, without a packet transport/cache/action deadline. The result transfers the sender-attribution stage only.

## Intervention and gate

At preregistered zero-based steps 0 and 20 of each of 24 fresh matched resets per seed, reset the independent environment to the same NumPy/Python state and replay the entire prefix. Force each of the four feasible sender masks once and then resume the native learned rule. The forced-factual sender must reproduce the complete factual trace, including state coordinates, policy observation/history, sender, sampled actions, rewards and done flags. All alternatives must reproduce the factual pre-intervention trace and consume precisely one slot at the target decision. If it terminates early there is no branch opportunity. The episode effect averages over its actually available registered decisions (the reset always supplies one). Each decision's contrast is factual suffix return minus the arithmetic mean across four sender suffixes; the sensitivity indicator is one if maximum and minimum suffix returns differ by more than 1e-8. Report state- and episode-weighted estimates, first aggregating within each of three independent seeds. Report individual seed means and unadjusted descriptive two-sided 95% Student-t intervals. Predeclare support for positive factual-choice advantage only if all three seed effects are positive and the episode-weighted interval excludes zero. Also report action-trace dependence, captures and available denominators.

From each matched reset also run a uniform-random predator actor with identical movement/action sets and prey stochasticity, and a zero-payload control using the native scheduler/history with all receivers supplied two zeros instead of the scheduled encoding. The learning gate compares normal return against random actions. The message-use gate compares normal return against the zero-payload reference; positive return claims require the same all-three-seed-positive/interval rule. Retain and label all counterfactuals on gate failure, distinguishing observed behavior from demonstrated learned value. No-op forced factual, payload-preserving graph intervention and identical-prefix checks are correctness requirements. Raw per-step arrays are compressed; keep raw per-decision and episode outcomes, per-condition elapsed CPU/wall time, counts and input hashes. Wire bytes, delivery cutoff and hardware latency are outside this native channel's definition.

## Completed run, 2026-11-28

The single-reset smoke passed both full-trace controls using reset 17203155, outside the registered sample. The full run restored the three registered weights and executed 844 trajectories, 40,437 environment transitions and 72 resets across checkpoints. All 72 full-episode payload shams, all 139 forced-factual complete trajectories and all 556 alternative prefixes/decision inputs matched their factual records exactly. All 556 branch decisions admitted one sender. There were 72 opportunities at step 0 and 67 at step 20. Five factual episodes ended before the second decision. Ten factual episodes ended by native capture, compared with eight zero-payload and three uniform-action episodes (72 each). Native capture is simultaneous prey visibility for all four predators. Physical enclosure determines a separate reward for the prey.

The joint policy acts beyond the uniform-action reference, while the value of the priority and payload remains unresolved.
