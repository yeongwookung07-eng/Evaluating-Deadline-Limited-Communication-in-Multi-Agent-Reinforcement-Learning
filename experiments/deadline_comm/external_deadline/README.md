The external Eccles et al. MNIST-sum reconstruction uses two agents, a20-symbol speaker and a19-action sum-predicting listener. The one-step task has no cross-episode cache. Exogenous readiness values100/300/600/900us are assigned in balanced, label-independent order, shared by all treatments; reception deadlines are250/500/750/1000/1250us. They are declared assumptions, not CPU/radio measurements or a complete action deadline. Full offers every message. Admission omits only messages known to miss reception; both therefore supply identical listener inputs/distributions, while offered modeled bytes may differ. A readiness0 restoration intervention delivers the same factual message distribution before every tested deadline; its reward difference tests whether restoring this information helps the already learned listener. Zero-message inputs represent absence, with no cached substitution.

The strongest control is paired Full–admission exact receiver/action-distribution identity. The alternative explanation is purely structural late-offer removal. Adoption requires separately successful learning, verified identity, and seed-level paired restoration effects. A full→admission offered-byte saving with identical use supports admission engineering only; an additional restoration gain supports delivery intervention in this model. No improvement means delivery restoration is not justified by these data. Original shuffle/influence controls may already establish message usefulness; the added diagnosis must be described narrowly as identifying modeled losses/admission opportunity, not discovering listening for the first time.
