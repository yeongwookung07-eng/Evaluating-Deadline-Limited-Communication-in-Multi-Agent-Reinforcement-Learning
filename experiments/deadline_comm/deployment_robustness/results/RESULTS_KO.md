# 체크포인트 고정 후속 평가 결과 — 2026-11-26

두 평가를 완료했다. 새 학습 없이 기존 MNIST-sum 정책 3개, broadcast 정책 10개와 이미 저장된 개선·무작위 라벨 헤드를 사용했다. 원고와 제출 파일은 변경하지 않았다.

## 준비시간 추정 오차와 판단 비용

수신 마감 750µs에서 준비시간 추정 오차를 평균 0, 표준편차 100µs로 두고, 모든 판단에 100µs를 추가로 부과했다. 비교 대상은 같은 평균 송신 비용을 쓰면서 추가 예측 비용은 없는 무작위 admission이다.

| 지표 | 결과 |
|---|---:|
| 추정 기반 admission 정확도 | 28.48% |
| 무작위 admission 정확도 | 19.23% |
| 짝지은 차이 | **+9.25%p [6.64, 11.85]** |
| 양쪽 평균 송신 비용 | 8.276 B/예제 |

따라서 정확한 준비시간을 몰라도 이 조건에서는 이득이 유지된다. 그러나 오차 표준편차 400µs·판단 비용 400µs에서는 +0.61%p [−0.09, 1.32]로 확실한 우위를 확인하지 못했다. 오차 800µs·비용 400µs에서는 **−1.35%p [−1.87, −0.82]**로 역전됐다.

또한 추가 판단 비용 없는 Full의 정확도는 29.37%다. 추정 기반 admission은 Full보다 0.89%p 낮다. “무작위보다 효율적”과 “Full과 같은 행동·성능을 보존”은 별도 주장이고, 후자는 추정 오차가 생기면 일반적으로 성립하지 않는다.

총 450개 사전 지정 조건(수신 마감 5개 × 오차 표준편차 6개 × 편향 3개 × 판단 비용 5개)을 모두 보존했다. 위 수치는 가정한 가우시안 추정 오차와 판단 비용의 정확한 기댓값이며, 실제 예측기를 학습하거나 측정한 결과는 아니다. 신뢰구간은 학습 seed 3개 기준의 기술적 95% t 구간이다. 기존 논문의 +10.59%p는 하나의 유한 무작위 마스크를 사용했고, 이번에는 무작위 admission도 정확히 평균했으므로 직접 같은 숫자로 취급하지 않는다.

## 늦은 행동을 실제로 차단한 평가

정상 접근에서 준비시간을 실측하고, 2ms 행동 마감을 넘긴 후보 행동은 이전 실제 행동 유지 또는 행동 0으로 대체했다. 실제 실행한 행동을 다음 순환 신경망 입력에 넣고 환경을 계속 진행했다. 과거 로그의 보상만 수정한 것이 아니다.

| 조건 | 원래 헤드 정확도 | 개선 헤드 정확도 | 개선 차이, 95% 구간 |
|---|---:|---:|---:|
| 정상 접근, 이전 행동 유지 | 57.69% | 63.31% | **+5.63%p [1.80, 9.46]** |
| 정상 접근, 행동 0 대체 | 57.68% | 63.30% | +5.61%p [1.80, 9.43] |
| 정상 접근, 250µs 추가 계산, 이전 행동 유지 | 56.90% | 62.35% | +5.45%p [1.99, 8.92] |
| 정상 접근, 500µs 추가 계산, 이전 행동 유지 | 47.75% | 47.75% | **0** |
| 특권적 source-aware 접근, 이전 행동 유지 | 47.75% | 47.75% | **0** |

주 평가인 정상 접근·이전 행동 유지에서는 독립 CPU 프로세스 세 번 모두 개선 헤드가 원래 헤드와 무작위 라벨 헤드보다 우수하다는 사전 기준을 통과했다. 원래 헤드 대비 차이는 각각 +5.67, +5.62, +5.59%p다. 프로세스 반복을 학습 seed 안에서 평균한 뒤 seed 10개로 구간을 계산했다. 모든 seed에서 개선된 것은 아니며 2개에서는 하락했다.

반면 500µs를 더 쓰면 후보 행동이 전부 늦어진다. 이를 그대로 적용하는 종래 방식에서는 여전히 +5.58%p로 보이지만, 실제로 차단하면 이득은 0이다. Source-aware 접근도 모든 후보 행동이 늦어, 그대로 적용할 때의 66.43%→86.57% 이득이 차단 후에는 사라진다. Source-aware 결과는 기존 고정 준비시간을 유지한 특권적 진단이며 정상 접근의 실측 준비시간 평가와 합치지 않았다.

47.75%는 이번 20개 공통 reset에서 항상 행동 0을 실행한 정확도다. 태스크 전체에 대한 보편적인 기준값이 아니다. 준비된 대체 행동을 마감 시점에 적용한다고 가정했으며 실제 액추에이터나 연속 시간 물리 환경을 검증한 것은 아니다. 개선 헤드는 과거에 정답 라벨로 학습된 것이므로 무감독 또는 label-free 개선을 주장할 수 없다.

## 논문에 사용할 수 있는 결론

- 제한된 추정 오차와 판단 비용에서는 timing-informed admission의 동일 평균 송신 비용 대비 이득이 유지된다. 오차와 계산 비용이 커지면 이득이 사라지거나 역전된다.
- 정상 접근에서 이미 학습된 수신기 개선 효과는 늦은 행동을 실제로 차단해도 유지된다. 계산 여유가 사라지면 그 이득도 사라진다.
- 따라서 정확도·보상만으로 마감 제약 아래의 효율을 판단하면 안 된다. 원래 논문의 전달·계산·제어 분리 평가 주장을 강화하는 결과다.

## 검증과 산출물

- Broadcast: 18,000 평가 에피소드, 360,000 단계, CPU 프로세스 3개. 제외된 warmup·smoke·과거 재현 검사는 별도다.
- MNIST-sum: 1,350 seed별 조건, 1,382,400 예제별 조건 계산.
- 기존 궤적 120개 정확 재현, 테스트 **22개 통과**.
- 독립 코드로 전체 로그의 행동 차단·환경 비트·보상·전달 시각·바이트·신뢰구간을 재계산했고 모두 통과했다.
- 모든 원본 체크포인트·헤드 해시와 평가 중 파라미터가 유지됐다. 새 학습·GPU 사용 없음.
- 본 평가 시간: MNIST 6.01초, broadcast 237.93 / 139.30 / 138.16초. 검증·smoke 시간은 별도다.
