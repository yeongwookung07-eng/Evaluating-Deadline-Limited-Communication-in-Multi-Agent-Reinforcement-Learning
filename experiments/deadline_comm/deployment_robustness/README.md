## MNIST-sum: uncertain preparation time and admission cost

Question: how far does timing-informed admission beat an equally costly random offer when readiness is estimated and estimation/admission costs time? Three existing 12k-update both-bias policies; same 1,024 held-out image pairs as the earlier external diagnostic (a sensitivity cohort, not new independent test data). Reload model weights, verify original hashes and independently recompute stored full/zero action distributions before evaluation. Two-agent, one-step learned image-sum task; no temporal cache.

Contract: true readiness r in {100,300,600,900} us; estimate r_hat=r+b+epsilon, epsilon Gaussian(0,sigma²). Negative estimates are permitted as an unbounded estimator-error model, not physical true readiness. Admission iff r_hat+c+220 <= D, where c is known sequential estimation/decision overhead and 220 us is 17 wire bytes / 100kB/s plus 50 us propagation. Actual arrival if offered is r+c+220. Exact Gaussian integration gives per-example offer probability p; exact speaker/listener marginalization gives reward. No sampled noise or outcome tuning. Cost is charged on every decision, including rejected offers. It does not model energy or a learned predictor.

Controls: Full with no extra overhead; Full with the same overhead; perfect timing at each overhead; RANDOM with p_bar offers independently of readiness, both with same overhead and with **zero incremental overhead** (strongest practical reference). Equal expected mean offered bytes, not identical realized per-example cost. Uniform fixed-count random subset marginal is p_bar when count is integral. Marginalization removes finite-random-mask variability; original sampled-random result remains separate. Preserve all 450 settings (5 deadlines ×6 SDs ×3 biases ×5 costs). Store per-example probabilities/rewards/true arrivals and seed-level intervals.

Primary, selected before outcomes: D=750, sigma=100, b=0, c=100 us. Conditional practical robustness requires paired seed-level 95% t lower bound >0 versus zero-extra-cost RANDOM. Same-cost positive but practical nonpositive indicates overhead defeats adoption. Report complete curves and boundary failures; three seeds and unadjusted grid intervals do not establish universal robustness or a multiple-comparison-confirmed region. Exact known-readiness/no-cost must recover Full–admit identity. No-information admission must equal random at same cost.

Entry: `python -m experiments.deadline_comm.deployment_robustness.mnist_uncertain_readiness --config experiments/deadline_comm/configs/mnist_uncertain_readiness.yaml`. Output `../runs/mnist_uncertain_readiness_20261126_001/`. CPU one thread, 600 s maximum; no fitting.

## Broadcast: actual rejection of late actions

Question: does the saved supervised follower-head gain survive a causal action deadline? Ten existing Oracle-free five-agent broadcast RR policies and **already fitted** true/shuffled-label heads, without updates. Horizon20; fresh independent source bit per step, four followers rewarded for current-bit accuracy. 20 new paired resets 26112600–26112619 per seed, disjoint from original head fitting/testing. Labels used only to score, never to fit/select in this experiment.

Primary normal-access evaluation uses measured preparation time in the existing serial link, 2ms deadline, 450us post reserve and 48-byte packets. Execute three independent one-thread CPU processes serially, two excluded warmup episodes per cell, alternating/rotating cell order. Arms original/adapted/shuffled × ordinary-late execution/hold previous executed joint action/fixed-zero fallback × extra post-compute overhead 0/250/500us. Overhead is modeled serial compute after the packet decision, no actual sleep. All steps charge the enclosing harness call plus modeled link wait plus overhead. Environment and logging are outside controller timing. A preinstalled fallback is assumed ready at the deadline; its external actuator switching is not benchmarked.

For hard arms, use the candidate only if total <= deadline. Otherwise execute previous actual action (initial all-zero) or all-zero. Store candidate and executed actions separately. Overwrite harness previous-action input with **executed** action, retaining computed recurrent state and caches; no rollback, asynchronous pipeline or continuous plant is modeled. Recurrent feedback therefore follows fresh full rollouts, never retrospective reward subtraction. Cache update and message delivery follow original rules. Counterfactual heads can change messages and delivery histories; those are outcomes, not assumed equal. Measured timing differs between arms and repeats, so observed contrasts include deployment timing variation.

Source-aware access is separately a privileged diagnostic: use historical fixed-ready selection and charge its clone/selection overhead in the action deadline, no claim of physically causal packet timing. Evaluate all three heads and fallbacks at zero extra cost in repeat0 only. Do not pool this diagnostic with measured normal access.

Controls: recover original fixed-ready ordinary episodes and saved adaptation traces exactly before production; force no misses and verify hard-vs-ordinary identity; force all misses and verify fallback execution, next recurrent input and correct rewards. Hash all source checkpoints/heads before and after; frozen parameters. Strongest benefit comparison is adapted vs original and shuffled under identical fallback/overhead/reset. Primary gate: zero-added-cost normal hold must beat both with positive unadjusted seed-level paired t interval **in each process repeat**. Aggregate repeats within each training seed (n=10, never n=30). Report miss rates, actual accuracy/return, offered/delivered bytes, senders/timestamps, CPU readiness and total wall time, full per-step traces, process-specific failures and overhead sensitivity. Hard actuation can avoid using late candidates without making computation itself timely.

Full without decision overhead remains29.369% at the primary deadline: uncertain admission does not preserve Full identity. The exact-random control differs from the prior sampled-mask control, explicitly documented in the results.
